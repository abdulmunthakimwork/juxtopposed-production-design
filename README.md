# Juxtopposed Production Design Skill

A comprehensive, production-grade UI/UX design and redesign methodology combining Juxtopposed's visual/structural intelligence with rigorous Figma and design-system standards.

## What it does

Teaches AI agents how to reason through visual hierarchy, layout selection, containerization, and brand identity to produce diverse, context-specific, production-ready interfaces without relying on fixed templates.

## When to invoke

Use when building new UI, redesigning existing interfaces, conducting design audits, or when users ask for production-grade UI/UX work on landing pages, dashboards, portfolios, or applications.

## Installation

```bash
# Clone to your Trae skills directory
git clone https://github.com/[your-username]/juxtopposed.git ~/.trae/skills/juxtopposed-production-design

# Or use the installation script
./skill.sh install
```

## Core Features

### 🎯 First-Principles Design Reasoning
- **Intentionality Over Ornamentation**: Every pixel must solve a specific problem
- **Structure Dictates Layout**: No universal templates - content shape determines layout
- **Personality Through Restraint**: One high-conviction choice vs. cluttered decoration
- **Subtraction Before Addition**: Remove before you add

### 📐 Layout Archetype System
Choose from 5 layout archetypes based on content needs:
- **High-Density Utility Canvas** for creation tools and complex workflows
- **Asymmetric Split/Editorial** for storytelling and brand-driven apps
- **Bento Box Modular Grid** for feature overviews and dashboards
- **Minimalist Centered Stream** for reading and single-task flows
- **Edge Navigation Canvas** for multi-view applications

### ✅ Self-Critique Loop
Every design passes rigorous validation:
- Diversity test (avoid generic templates)
- Subtraction test (eliminate visual noise)
- Eye-tracking test (natural visual flow)
- Squint test (clear primary CTA)
- Accessibility & Contrast test (WCAG 2.1 AA compliant)

## Usage

The skill automatically activates when Trae detects UI/UX design tasks, or you can explicitly invoke it:

```
Use juxtopposed-production-design to redesign this landing page
```
